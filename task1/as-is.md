# Проблемные зоны

| №   | Описание проблемы                                                                |
|-----|----------------------------------------------------------------------------------|
| 1   | Нет разграничения доступа в к файлам с персональными данными пациентов           |
| 2   | Нет разграничения доступа в к файлам с медецинскими данными пациентов            |
| 3   | Нет шифрования файлов с персональными и медецинскими данными                     |
| 4   | Нет аудита изменений файлов с чувствительной информацией                         |
| 5   | Нет резервных копий чувствительных данных                                        |
| 6   | Данные доступны всем пользователям (нет ролевой модели, только авторизация ldap) |
| 7   | Нет регламента по хранению и удалению пользовательских данных                    |
| 8   | Отсутствует ПО для безопасности в системе (антивирусы/фаерволы)                  |
| 9   | Хранение персональных данных на общем сервере с другим ПО                        |
| 10  | Хранение финансовой информации так-же в общедоступных файлах                     |

# Предложения по улучшениям

| 9   | Провести обучение персонала                              |
